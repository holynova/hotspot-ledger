# 热点账本

一个本机运行的 macOS 流量记录工具。0.3.5 采用「排行优先」小窗口：密集速度柱形图、真实应用图标、合并应用排行、浅色/黑色主题、按连接保存历史，以及手动和可选的自动关闭 Wi-Fi。

## 使用

打开 `/Applications/热点账本.app`。首次运行时请添加需要记录的热点。

- 其他热点：在主界面点击「记录此 Wi-Fi」，或在设置中添加 Wi-Fi 名称。
- 应用运行时，连接计费网络会自动建立会话；断开、切换网络、睡眠后结束会话。完全退出后重启，若首次采样仍为同名热点和同一网卡，则续接最近一次因退出或中断结束的记录。退出期间流量不计入，记录时长扣除该间隔；同名网络不代表连续连接。
- **关闭窗口仍继续采集**，通过菜单栏 Wi-Fi 图标重新打开。完全退出或电脑重启后需要手动打开；本版不安装登录项或后台守护服务。
- 「Wi-Fi 出口」显示通过物理 Wi-Fi 的进程采样用量。
- 「应用活动」包含代理前、回环及其他网卡的进程流量，用于查出具体程序。它不是另一份手机流量账单，不能和出口值相加。
- 点击进程，查看可执行文件、工作目录和可识别的任务类型（例如 `wrangler deploy`）。不保存完整命令行，避免将令牌和密码写进历史。
- 底部「历史」选择历史连接。「传输速度 ↗」切换数据表，柱形图支持悬停查看上传/下载速度。
- 默认累计 500 MB、60 秒传输 100 MB 提醒。填 0 可关闭对应提醒。系统通知需在 macOS 授权，未授权时仍显示窗口内提醒。

## 统计口径与已知限制

1. 总量来自 `netstat -ibn -I <Wi-Fi 接口>` 的 64 位接口计数差，不将 IPv4/IPv6 地址行重复相加。单位是十进制 MB/GB。
2. 进程统计来自系统 `nettop`，约每 2 秒采样一次。首次出现的进程只建立基线；短连接、进程退出、计数器下降可能漏记。它是估计值，不是精准审计账单。
3. Clash / Mihomo 转发流量明确标为代理；本版不自动把它分摊给源应用。TUN 模式下可以从「应用活动」定位上传者，两层数据不能相加。
4. 以进程为记录单位，界面按应用包路径合并辅助进程；详情显示合计用量与用量最高进程的路径、编号及任务。PID 复用且可执行路径相同的极端场景尚未做进程启动时间校验。
5. 接口总量包含局域网及协议开销，不等同于手机或运营商账单。多个网卡同时活动时，辅助进程视图包含其他网卡。
6. SSID 通过 CoreWLAN 获取，失败后尝试 `networksetup`。在限制读取 SSID 的 macOS 版本上可能需要定位权限；读取不到时明确停止自动计费，绝不猜测网络身份。当前已在 macOS 14.8.1 上验证。
7. 采样间隔超过 15 秒会拆分会话，间隔内的用量无法可靠归属，因此不计入；切网时的最后几秒也可能漏记。
8. 历史会话保存累计用量与最多 450 个速度点（约 15 分钟）；不是整天逐秒轨迹。重启续接时保留累计和应用排行，速度图从新采样重新开始。
9. 手动「关闭 Wi-Fi」调用 CoreWLAN 关闭无线接口，避免自动重连；可用「开启 Wi-Fi」恢复。自动关闭默认关闭，在设置中启用并设独立累计阈值（默认 1000 MB）。仅对正在记录的热点生效，每次连接最多尝试一次，失败显示原因。重连后建立新会话，累计从零开始。关闭 Wi-Fi 不会关闭以太网或终止应用；采样有延迟，因此不是严格流量上限。

自动断连在真正操作前再次核对 Wi-Fi 名称；网络已改变时不执行。CoreWLAN 操作在部分系统上可能需要管理员权限，失败不会被当作成功。未主动切断当前网络做测试。

## 数据

`~/Library/Application Support/Hotspot Ledger/ledger.json`

JSON 原子写入，文件权限 0600，目录权限 0700。损坏的历史不会被空数据库覆盖；窗口会显示存储错误。首次启动时将未结束的旧会话标记为采集中断，避免把退出期间流量算进新会话。

## 构建

本版要求 Apple Silicon、macOS 14+，使用系统 Swift 和 SDK，无第三方运行依赖，也没有构建下载步骤。

```sh
./scripts/build.sh
./scripts/build.sh test
```

产物：`dist/热点账本.app`，本地 ad-hoc 签名，尚未通过 Apple 公证。构建脚本对本机重复的 SwiftBridging 模块提供项目内 VFS overlay，并选用已安装的 macOS 14.5 SDK，不修改系统工具链。

`Sources/Probe.swift` 是独立真实采集探针，不纳入应用可执行文件。

## 设计

经过三方案探索后，当前正式界面采用用户选定的「排行优先」。审计按用户提供的标准 1–10 编号记录在 `docs/ui-audit-0.3.5.md`，原型不纳入应用运行时。图标采用用户选定版本。

## 开发预览

`--preview` 或 `.preview` bundle ID 使用内存示例数据，禁用采集、磁盘写入和真实 Wi-Fi 操作。`--preview-long` 用于长中英文名称排版检查。正式应用通过文件锁防止多个新版本实例同时写记录。

## 0.3.5 界面

正式窗口复用方案 1 的 HTML/CSS，由本机 WKWebView 加载内置文件；采集、存储与断连仍由 Swift 执行。默认 384 × 614 px。滚动条为不占宽度的 3 px 暖灰浮动指示条，滚动或移入时显示，900 ms 后淡出；保留触控板及键盘滚动。

0.3.5 将统计范围和排序改为常显单选按钮组，代理转发在独立区域展示；修正原生拖动区域遮挡底部按钮的问题。已在安装后的应用中实际点击验证主题、历史、设置和两组单选切换。
